# Сайт HC ICE HOOLIGANS

Статичная страница со статистикой команды. Данные берутся из открытого API Хоккейной Лиги
«Трудовые Резервы» и **пересобираются автоматически каждую ночь в 00:00 по Москве**
средствами GitHub Actions — компьютер для этого не нужен.

```
index.html            готовая страница (её отдаёт GitHub Pages)
src/head.html         вёрстка и стили
src/app.js            логика страницы
src/data.js           данные, генерируются скриптом — руками не править
build/collect.mjs     сбор статистики из API лиги
build/build.mjs       сборка index.html
.github/workflows/    ночное расписание
CNAME                 домен icehooligans.ru
```

## Как запустить один раз

1. Создать на GitHub **публичный** репозиторий, например `icehooligans`.
2. Загрузить в него содержимое этой папки (кнопка «Add file → Upload files» или `git push`).
3. **Settings → Pages** → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` → Save.
4. Там же в **Pages → Custom domain** вписать `icehooligans.ru` и нажать Save,
   затем включить галочку **Enforce HTTPS** (появится через 10–30 минут после проверки домена).
5. **Settings → Actions → General → Workflow permissions** → выбрать
   `Read and write permissions` (иначе ночной коммит не пройдёт).

## Обновление

- **Автоматически** — каждую ночь в 00:00 МСК. Если после матчей ничего не изменилось,
  коммит не создаётся.
- **Вручную** — вкладка `Actions` → `Обновление статистики` → `Run workflow`.
  Это же пригодится, если GitHub усыпит расписание: он отключает ночные запуски
  в репозиториях, где 60 дней не было активности, и присылает письмо — достаточно
  нажать «Enable workflow».
- **Локально** — `node build/build.mjs` (нужен Node 20+; зависимостей нет).
  Флаг `--offline` пересобирает страницу из сохранённых данных, не обращаясь к API.

Перед записью файлов скрипт сверяет данные сам с собой: число матчей и сумма шайб по
протоколам должны совпадать с итогами сезонов. Если не совпало — сборка падает,
и на сайте остаётся прежняя рабочая версия.

## Что откуда берётся

| Раздел | Источник |
|--------|----------|
| Матчи, счёт, арены | `tournament/{id}/games/` |
| Статистика игроков и вратарей | `hockey_statistic/` (POST) |
| Турнирные таблицы | `tournament_round/{id}/teams/` |
| Заявка, капитан, тренер | `tournament_team/{id}/users/` |
| Достижения и фото игроков | профиль игрока в лиге |
| Фотоархив матчей | `league/12/media/` |

Фотографии и логотип подгружаются с сервера лиги (`fs.mtgame.ru`), в репозитории не хранятся.

## Если лига поменяет API

Сборка упадёт с понятной ошибкой, а сайт продолжит работать на последних данных.
Править нужно `build/collect.mjs` — вся работа с API собрана там.
